# Quiz das Bandeiras v1.0.0

Primeira versão compartilhada do aplicativo acadêmico desenvolvido em Android Studio.

## Incluído

- Quiz com 10 bandeiras e quatro alternativas por questão;
- Resultado personalizado com total de acertos;
- Ranking local persistente usando SharedPreferences;
- APK de demonstração para testes.

> Esta é uma build de debug destinada a demonstração e testes acadêmicos.
